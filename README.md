## 开源项目

以下是我的开源项目：

<details>
<summary><strong><a href="https://github.com/ZyanWan/Skill-Hub">Skill-Hub</a></strong> · <code>Python</code> — 收录 367 个标准化技能包、12 大分类的 Agent Skills 技能库与管理系统</summary>

面向 AI 编程助手的 Agent Skills 技能库与管理系统，收录 367 个标准化技能包、12 大分类，覆盖 Claude Code / Cursor / Codex / Gemini CLI 等主流助手；配套零依赖 CLI（skill-tool.py）与本地可视化 Skill Manager 平台（React + Fastify）。

</details>

<details>
<summary><strong><a href="https://github.com/ZyanWan/Patchright-Agent-RPA">Patchright-Agent-RPA</a></strong> · <code>TypeScript</code> / <code>Python</code> — 面向 AI Agent 的真实浏览器自动化技能层</summary>

面向 AI Agent 的真实浏览器自动化技能层：基于 Patchright 封装持久化会话、页面探测、受控操作与证据留存，可通过 npm 安装器分发给 Codex / Claude Code，支持按业务领域封装独立 Skill。

</details>

<details>
<summary><strong><a href="https://github.com/ZyanWan/Session-Engram">Session-Engram</a></strong> · <code>Python</code> — 基于 Hook 机制的跨会话记忆系统</summary>

面向 AI 编程助手的跨会话记忆系统：用 Markdown 持久化会话与可复用经验，基于 Hook 机制让 AI 在新会话开始时自动读取记忆；内置交互式知识图谱、时间线与全局经验库，支持 Claude Code / OpenCode / Cursor。

</details>

<details>
<summary><strong><a href="https://github.com/ZyanWan/Zyan">Zyan</a></strong> · <code>React</code> / <code>TypeScript</code> — 集对话、MCP 管理、Agent 配置与工作流画布于一体的平台原型</summary>

现代 AI Agent 平台产品原型：对话、MCP 管理、Agent 配置、可视化工作流画布（ReactFlow）与知识库五大模块，Vite + React 18 + Zustand + Tailwind CSS v4，支持深色 / 浅色主题。

</details>

<details>
<summary><strong><a href="https://github.com/ZyanWan/Hanzi-Etymology-Animation">Hanzi-Etymology-Animation</a></strong> · <code>Python</code> — 自动生成汉字从甲骨文到楷书演变动画的教学工具</summary>

面向对外汉语教学的汉字词源动画工具：自动抓取汉字从甲骨文到楷书的字形数据，经阿里云 Wan2.7 生成连续演变动画，并配火山引擎 TTS 语音解说，帮助学生理解汉字为何长成现在的样子。

</details>
