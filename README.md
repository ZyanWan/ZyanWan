## 🔭 Current Projects

### [Session-Engram](https://github.com/ZyanWan/Session-Engram)
Cross-session memory system for AI coding assistants. Enables persistent conversation context, task progress, and reusable experiences across different sessions. Features Hook-based auto-recall, interactive knowledge graph visualization, timeline organization, and global experience library. Supports Claude Code, Cursor, and OpenCode.

### [Patchright-Agent-RPA](https://github.com/ZyanWan/Patchright-Agent-RPA)
Browser automation RPA project designed for AI Agents. Built on Patchright with enhanced stealth and anti-detection capabilities, enabling AI agents to operate real web applications in a reusable, inspectable manner. Includes browser control, persistent sessions, page detection, controlled operations, evidence retention, and task workflows.

### [Zyan](https://github.com/ZyanWan/Zyan)
Full-stack AI Agent platform (design prototype) integrating conversational AI, MCP protocol, intelligent agents, knowledge base, and workflow orchestration. Tech stack: React 18, TypeScript, Zustand, Tailwind CSS, Fastify, PostgreSQL. Features RAG vector search, visual workflow orchestration, and multi-model switching.

### [Hanzi-Etymology-Animation](https://github.com/ZyanWan/Hanzi-Etymology-Animation)
Tool for creating Chinese character evolution animations. Automates the process of fetching etymology data, converting historical scripts (Oracle Bone, Bronze, Seal, Clerical, Regular) to SVG/PNG formats, generating smooth evolution animations via Alibaba Cloud Wan2.7 AI video model, and producing voice narration with Volcano Engine TTS. Designed for Chinese language teaching.
