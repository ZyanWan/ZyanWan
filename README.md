## 开源项目

以下是我的开源项目，如有感兴趣的同志，欢迎联系我进一步交流。

### [Skill-Hub](https://github.com/ZyanWan/Skill-Hub) · `Python`

面向 AI 编程助手的 Agent Skills 技能库与管理系统，收录 367 个标准化技能包、12 大分类，覆盖 Claude Code / Cursor / Codex / Gemini CLI 等主流助手；配套零依赖 CLI（skill-tool.py）与本地可视化 Skill Manager 平台（React + Fastify）。

### [Patchright-Agent-RPA](https://github.com/ZyanWan/Patchright-Agent-RPA) · `TypeScript` / `Python`

面向 AI Agent 的真实浏览器自动化技能层：基于 Patchright 封装持久化会话、页面探测、受控操作与证据留存，可通过 npm 安装器分发给 Codex / Claude Code，支持按业务领域封装独立 Skill。

### [Session-Engram](https://github.com/ZyanWan/Session-Engram) · `Python`

面向 AI 编程助手的跨会话记忆系统：用 Markdown 持久化会话与可复用经验，基于 Hook 机制让 AI 在新会话开始时自动读取记忆；内置交互式知识图谱、时间线与全局经验库，支持 Claude Code / OpenCode / Cursor。

### [Zyan](https://github.com/ZyanWan/Zyan) · `React` / `TypeScript`

现代 AI Agent 平台产品原型：对话、MCP 管理、Agent 配置、可视化工作流画布（ReactFlow）与知识库五大模块，Vite + React 18 + Zustand + Tailwind CSS v4，支持深色 / 浅色主题。

### [Hanzi-Etymology-Animation](https://github.com/ZyanWan/Hanzi-Etymology-Animation) · `Python`

面向对外汉语教学的汉字词源动画工具：自动抓取汉字从甲骨文到楷书的字形数据，经阿里云 Wan2.7 生成连续演变动画，并配火山引擎 TTS 语音解说，帮助学生理解汉字为何长成现在的样子。
